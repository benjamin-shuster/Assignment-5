## Contract Check Report (`frontend/app.js` ↔ `docs/spec.md` §4–6 ↔ `app/routes.py` & `app/`)

Overall: All HTTP endpoints, methods, paths, query/body fields, response shapes, and the six error codes in `docs/spec.md` sections 4–6 **match** between `frontend/app.js`, `docs/spec.md`, and the backend (`app/routes.py`, `app/service.py`, `app/repository.py`, `app/main.py`).

There is **one mismatch** regarding `daily_limit`: `frontend/app.js` defines a user message for error code `daily_limit` (and `docs/spec.md` §7 D1 mentions `daily_limit` returning `422`), whereas `docs/spec.md` §§4–6 do not define any daily-limit rule or `daily_limit` error code, and the backend does not enforce or return `daily_limit`.
